# Cricket Automation Testing Project


## Overview
Complete test automation framework for cricket scoring 
web application built using Java, Selenium WebDriver, 
TestNG and RestAssured API testing.

## Tech Stack
- Java 17
- Selenium WebDriver 4.18
- TestNG 7.9
- Maven
- WebDriverManager
- RestAssured 5.4
- Git/GitHub

## Test Files
### 1. CricketTest.java
- Verify ESPNcricinfo home page title
- Verify page URL loads correctly
- Verify cricket scores page loads

### 2. CricketAppTest.java
- Verify cricket app page title
- Verify Add Runs functionality
- Verify Add Wicket functionality
- Verify Reset Scores functionality

### 3. CricketApiTest.java
- Verify API response status code 200
- Verify API response body content
- Verify API response time under 5 seconds
- Verify multiple posts API endpoint

## Total Tests: 11 automated tests - All Passing

## How to Run Tests
1. Clone this repository
2. Open in Eclipse IDE
3. Right click test file
4. Run as TestNG Test
