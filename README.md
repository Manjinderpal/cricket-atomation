# Cricket Automation Testing Project

## Overview
Automated testing framework for cricket scoring web application
built using Java, Selenium WebDriver, and TestNG.

## Tech Stack
- Java 17
- Selenium WebDriver 4.18
- TestNG
- Maven
- WebDriverManager
- Git/GitHub

## Test Cases
1. Verify ESPNcricinfo home page title
2. Verify page URL loads correctly
3. Verify cricket scores page loads

## How to Run Tests
1. Clone this repository
2. Open in Eclipse IDE
3. Run as TestNG Test
